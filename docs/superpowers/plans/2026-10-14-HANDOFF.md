## Decisions already made with the user (do not re-litigate)

- **Downloads come back.** The scope is: CivitAI and HuggingFace downloads, CivArchive and CivitAI hash lookups, and upstream's sources and source chain, ported file-by-file with `git show bec5c80:<path>`. Never add a remote, merge or rebase from upstream.
  - The `bec5c80` objects are present locally.
  - Fallback if they are not: `gh api "repos/kianxyzw/comfyui-model-linker/contents/<path>?ref=bec5c80" -H "Accept: application/vnd.github.raw"`.
- **Background lookups run on their own, but never block anything.**
  - `/analyze` only reads the store and queues work.
  - Results persist in `data/lookups.json`, so they show up when the dialog is reopened.
  - The `auto_lookup` setting is on by default and can be switched off.
- **Similar-model search** (Plan B Task 8):
  - Runs only when the user asks.
  - Candidates are scored with this fork's matcher; different sizes are labelled "different model".
  - A chosen file is saved under **its own filename, never the workflow's**.
  - Results never become a `download_source`.
- **Lora Manager sidecars** (Plan B Task 6):
  - `<stem>.metadata.json` plus a preview are written next to each download, in **Lora Manager v1.2.5's** format: 8 required keys, `sub_type` and not `model_type`, three-state `autov3`.
  - Lora Manager is GPL-3.0 and this repo is MIT: **implement the format and copy no Lora Manager code.**
  - Lora Manager was updated from 1.2.3 to 1.2.5 on 2026-10-14. A backup of the old files is in the earlier session's scratchpad. Nothing else to do there.
- **Filling empty Lora Manager info from HuggingFace** (Plan B Task 9):
  - Identify each file's repo **by SHA-256 only** (an existing link, the bundled index, or a name search verified against HuggingFace's LFS hashes). Never link by name.
  - Then have Lora Manager link and hydrate the model through its own routes.
  - AI enrichment is opt-in.
  - Existing trigger words are preserved.
- **No DOM scraping.** The load-time notice uses `afterConfigureGraph` (Plan C Task 3), not upstream's `MutationObserver` on the Missing Models popup.
- Upstream's known bugs are **not** ported. The plans list them.
